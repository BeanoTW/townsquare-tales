# Townsquare Tales

Same vibe as Stick RPG. Stick man town, just leveling up stats meeting random people. Go legit or go crooked. Upgrade house, go school. That kind of stuff. Pretty basic game but weirdly fun

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://townsquare-tales.lovable.app
